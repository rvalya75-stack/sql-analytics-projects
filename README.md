# SQL Analytics Projects

Репозиторий содержит проекты по SQL-аналитике: анализ бизнес-метрик, пользователей и клиентского поведения.

## Используемые технологии
- PostgreSQL
- SQL
- Metabase

## Проекты

### 01. Анализ выручки и среднего дохода пользователей
Задачи:
- расчет месячной выручки;
- количество пользователей;
- средний доход пользователя.

Навыки:
- JOIN
- GROUP BY
- агрегатные функции
- работа с датами

### 02. Анализ динамики платежей
Задачи:
- анализ изменения платежей во времени;
- расчет скользящих средних.

Навыки:
- оконные функции;
- AVG() OVER();
- ROWS BETWEEN.

### 03. Анализ клиентов взыскания
Задачи:
- анализ структуры задолженности;
- сегментация клиентов;
- расчет долей займов.

Навыки:
- JOIN;
- CASE WHEN;
- оконные функции.

### 04. Когортный анализ пользователей
Задачи:
- определение когорт пользователей;
- анализ активности;
- расчет Retention.

Навыки:
- CTE (WITH);
- COUNT DISTINCT;
- DATE_TRUNC.

### 05. Анализ пользователей с платежами и активностью
Задачи:
- поиск активных пользователей;
- анализ поведения пользователей с платежами.

Навыки:
- подзапросы;
- JOIN;
- HAVING;
- агрегатные функции.
