SQL Analytics Projects

Описание:

Набор аналитических SQL-проектов с использованием агрегатных функций, JOIN, подзапросов и оконных функций.
Выполнен анализ пользовательского поведения, платежей, когорт и бизнес-метрик.

## SQL проекты

### 1. Анализ выручки и пользовательской активности

Файл: `01_revenue_analysis.sql`

Расчет ключевых бизнес-метрик:
- месячная выручка;
- количество пользователей;
- средний доход на пользователя.

Использованы:
- JOIN;
- GROUP BY;
- DATE_TRUNC;
- агрегатные функции.


### 2. Анализ динамики платежей

Файл: `02_window_functions_analysis.sql`

Анализ изменения платежей во времени с расчетом скользящих средних.

Использованы:
- оконные функции AVG() OVER();
- ORDER BY;
- ROWS BETWEEN;
- подзапросы.
